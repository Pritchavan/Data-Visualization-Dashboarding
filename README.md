# 📊 Sales & Revenue Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Sales & Revenue Analysis Dashboard** built using **Microsoft Power BI**.

The dashboard analyzes sales performance across different categories, regions, cities, products, and years. It provides key business metrics and interactive filters to help understand sales trends and identify top-performing products and regions.

---

## 🎯 Project Objective

The main objective of this project is to:

- Analyze overall sales performance
- Track sales trends over time
- Compare sales across different regions
- Analyze sales by product category
- Identify the Top 10 products by sales
- Provide important business KPIs
- Create an interactive and user-friendly dashboard

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel / CSV**
- **Data Visualization**

---

## 📂 Dataset

The project uses the **Sample Superstore Dataset**.

The dataset contains information about:

- Orders
- Customers
- Products
- Categories
- Sales
- Profit
- Quantity
- Regions
- Cities

- Ship Date

## 📊 Dashboard Features

### 🔹 KPI Cards

The dashboard includes the following key performance indicators:

- **Total Sales:** 2.30M
- **Total Customers:** 793
- **Total Orders:** 5K

### 🔹 Visualizations

The dashboard contains:

1. **Sales by Category**
   - Compares sales performance across different product categories.

2. **Sales Trend by Month**
   - Shows how sales change over time.

3. **Sales by Region**
   - Compares sales performance across Central, East, South, and West regions.

4. **Sales Distribution by Category**
   - Displays the percentage contribution of each category to total sales.

5. **Sales by City**
   - Geographic visualization showing sales distribution across locations.

6. **Top 10 Products by Sales**
   - Identifies the highest-selling products.

7. **Category & Region Analysis**
   - Provides a detailed comparison of sales across categories and regions.

---

## 🎛️ Interactive Filters

The dashboard includes interactive filters/slicers for:

- **Category**
- **Region**
- **Year**

These filters allow users to dynamically explore the dashboard and analyze specific segments of the data.

---

## 💡 Key Insights

Some important insights obtained from the dashboard include:

- The **Technology** category contributes significantly to overall sales.
- The **West** region has the highest sales among the regions.
- Sales vary considerably across different products.
- A small group of products contributes a significant portion of total sales.
- Sales show fluctuations across different months and years.
- The dashboard can be filtered by category, region, and year for detailed analysis.
